# Testler

Henüz uygulama kodu, test veya test çalıştırıcısı yoktur.

İlk özellik ile birlikte beklenen kullanıcı davranışını doğrulayan testler ekleyin. Başarı, hata ve ilgili sınır durumlarını kapsayın; sentetik veri kullanın. Kurulum ve test komutları kök README'de açıklanmalıdır.

Bu dosyanın bulunması testlerin çalıştığı veya başarılı olduğu anlamına gelmez.
